# Deploy artifacts for WebLab#4 and WebLab#5

- `docker-compose.lab4.yml` - маршрутизация web-server v1.0
- `docker-compose.lab5.yml` - балансировка, mirror, monitoring
- `nginx/lab4.conf` - конфиг для WebLab#4
- `nginx/lab5.conf` - конфиг для WebLab#5
- `static/` - страницы `/`, `/legacy`, `/managment`, `/mirror`, картинки
- `reports/` - markdown отчеты и чеклисты
